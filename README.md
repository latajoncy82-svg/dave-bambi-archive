# Dave & Bambi Character Archive

Browse 420 source-linked characters, alternate forms, and fan creations.

[Open the archive](https://latajoncy82-svg.github.io/dave-bambi-archive/)

This static site can also run from disk. Open `index.html` in a browser. The catalog and filters work offline. Portraits and reference links need an internet connection.

See [VALIDATION.md](VALIDATION.md) for the database and browser checks.
